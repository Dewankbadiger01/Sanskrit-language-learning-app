### Sanskrit Sound Learning & Pronunciation Practice Platform

SvaraVarga is a web application for learning **Sanskrit sounds, phonetics, and pronunciation** through interactive lessons and audio analysis.

## ✨ Features

- 📚 Learn Sanskrit vowels & consonants
- 🗺️ Sanskrit sound/articulation chart
- 🎙️ Record pronunciation
- 🔊 Listen to sounds
- 🧠 Audio analysis using MFCC & spectral features
- 📊 Pronunciation score
- 🎯 Practice and progress tracking

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, CSS  
**Backend:** Python, Flask  
**Audio Analysis:** Librosa, NumPy, SoundFile
